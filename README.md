## 1. Project Overview

The Weather Dashboard is a responsive web application that retrieves real-time weather information using the OpenWeather API.

Users can search for a city and view the current weather conditions and a five-day forecast.

The application also provides temperature unit selection, light/dark theme switching, Local Storage persistence, loading states and error handling.

---

## 2. Project Objectives

The main objectives are:

- Understand REST APIs.
- Work with JSON responses.
- Use Promises and async/await.
- Fetch data using JavaScript.
- Display real-time weather information.
- Implement five-day forecast functionality.
- Use Local Storage for user preferences.
- Implement error handling.
- Create a responsive and accessible interface.
